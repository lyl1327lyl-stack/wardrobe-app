# 穿着记录日历页 美化与功能增强 设计文档

> 日期：2026-07-09
> 目标文件：`src/screens/WearCalendarScreen.tsx` 及相关组件

## 目标

当前穿着记录页（月份日历 + 月度概览卡 + 最近一周）功能完备但视觉单调、缺乏"今天"的存在感与回访动力。本次在不改变核心交互（点格子查看/记录当天）的前提下，增加 4 个模块让页面"活起来"：

- **A. 今日穿搭 Hero 卡** —— 顶部醒目的"今日"卡
- **B. 连续打卡 + 本月进度** —— 轻量游戏化
- **C. 月/年视图切换** —— 年度热力图（保留月份日历为默认）
- **D. 月度智能洞察** —— 数据自动生成 1-3 条小结

## 页面结构（从上到下）

1. 顶栏（保留：返回 / 标题"穿着记录" / 非当月时的"今天"按钮）
2. **A 今日 Hero 卡**（新）
3. **B 连续记录 + 本月进度**（新）
4. 日历卡 —— **默认月视图**，右上角「月/年」切换；选「年」→ **C 年度热力图**替换网格区域
5. 月度概览统计卡（保留）
6. **D 月度智能洞察**（新，1-3 条）
7. 最近一周卡（保留）

关键原则：**A、B 恒定指向"今天 / 本月"**，不随翻页月份变化（避免用户翻到历史月时看到误导性今日数据）；**D、月度概览跟随当前查看的月份**。

---

## A. 今日穿搭 Hero 卡

**位置**：顶栏下方，整宽渐变卡（主题色渐变 `primary → primaryDark`）。

**状态**：
- **已记录**：左侧"今日 · M月D日 周X"+"今日穿搭"标题；右侧横向最多 3 个衣物缩略图（第 3 个角标 `+N` 表示超出）。点击整卡打开当天的 WearCalendarSheet。
- **未记录**：渐变卡右侧一个白色"记录今日穿搭"按钮（渐变底 + 白字 + `add-outline` 图标）。点击 → `navigation.navigate('RecordWear', { date: today })`。

**数据**：当天（today）的穿着记录。复用 `wearRecordsDb.getWearRecordsByDateRange(today, today)` 或直接从已加载的 `wearData[today]`（当查看当月时即命中；为稳妥单独查询一次 today）。

**边界**：today 无记录且无衣物 → 仍显示未记录 CTA。

---

## B. 连续记录 + 本月进度

**位置**：A 下方，两张并排白卡。

**左卡 · 连续记录**：`🔥 N 天` + 副标题"连续记录"。
- 定义：从今天往前数**连续有穿着记录**的天数；若**今天尚无记录，则从昨天起算**（不因当天还没记录而断链）。
- 计算：拉取最近 60 天记录，得到有记录的日期集合，按上述规则计数。

**右卡 · 本月进度**：`N/D` 数字 + 进度条 + "本月天数"。
- 分子 = 当前自然月（today 所在月）已记录天数；分母 = 该月总天数。
- 进度条 = `primary` 渐变，宽度 = 分子/分母。
- 数据：拉取当月记录（`loadMonthData` 在查看当月时已含；单独按 today 的年月查询一次保证准确）。

**边界**：N=0 时左卡显示"0 天"+ 灰色火焰；进度 0 时进度条空。

---

## C. 月/年视图切换 + 年度热力图

**交互**：日历卡标题行右侧加「月 | 年」分段切换。默认「月」。

**月视图**：保留现有 `MonthCalendar`。增强：格子背景按当天穿着件数分档着色（0=无色，1-2=浅，3-4=中，≥5=深，用 `primary` 的不同 alpha），让月份网格本身就有活跃度可视化。其余交互不变（点格子出 Sheet、翻月、今天高亮、周末色）。

**年视图**：同一区域替换为**全年热力图**（`YearHeatmap` 新组件）：
- 显示 `currentYear` 全年（1-12 月），每行一周、每列一月或经典的"12 月份块"布局（参考现有 `WearHeatmap` 风格：每月一小块，1 号置于首行首列，列=ceil(天数/7)）。
- 每格颜色深浅 = 当天穿着件数（0=底色，分档同月视图）。
- 点格子弹出到该天的 Sheet（复用 `handleDayPress`）。
- 月份标签在每块顶部。

**数据**：年视图需整年记录 → 拉取 `currentYear` 的 1/1 ~ 12/31 范围记录（懒加载，仅切到「年」时查询并缓存）。

**边界**：未来日期不可点（同月视图 `disableFuture` 语义）。

---

## D. 月度智能洞察

**位置**：月度概览卡之后、最近一周之前。最多 3 条白底卡，左侧 emoji + 一句话。

**规则**（基于当前查看月份的 `wearData` + `allClothingMap`，按优先级取前 3 条，不满足条件则跳过）：

1. **颜色偏好** —— 统计当月被穿衣物（去重）的颜色；若 top 颜色占比 ≥ 30% 且有颜色数据的衣物 ≥ 3 件：`🖤 本月最爱穿 {色}，占 {N}%`。
2. **周末 vs 工作日** —— 计算当月周末日均穿着件数 vs 工作日日均；若周末日均 ≥ 1.5× 工作日日均 且 周末记录天数 ≥ 2：`📅 周末穿搭比工作日丰富 {倍数}×`（倍数四舍五入）。
3. **闲置提醒** —— 从全部在库且**当季**的衣物中，找 `lastWornAt` 最久（且 > 30 天）的一件：`💤 {类型/备注} 已 {N} 天没穿`。（跨月，但提供回访动力。）

**边界**：三条都不满足 → 整个洞察区块隐藏（不留空白卡）。

## 组件拆分

为避免 `WearCalendarScreen.tsx`（现 ~600 行）继续膨胀，新增模块抽成独立组件，置于 `src/components/`：

- `TodayOutfitHero.tsx` —— A。props: `items: ClothingItem[]`, `today: string`, `onPress()`, `onRecord()`.
- `StreakProgressCard.tsx` —— B。props: `streakDays: number`, `monthRecordedDays: number`, `monthTotalDays: number`.
- `YearHeatmap.tsx` —— C 年视图。props: `year`, `wearData: Record<string, ClothingItem[]>`(或日期→件数映射), `today`, `onSelectDate()`, `disableFuture`.
- `CalendarInsights.tsx` —— D。props: `insights: Insight[]`（屏幕内计算好后传入，组件只负责渲染）。

`MonthCalendar.tsx` 增量改动：新增可选 prop `cellTint?: (dateStr, count) => string | undefined`，用于月视图格子按件数着色；默认行为不变（其他调用方不受影响）。

数据计算（streak / progress / insights / 年度记录）保留在 `WearCalendarScreen` 内，用 `useMemo` + 异步 `useEffect` 拉取。

## 数据流

- `wearData`（当前查看月，已有）→ 喂给 月视图着色、月度概览、D 洞察。
- 新增 state：`todayItems`（当天记录）、`streakDays`、`currentMonthProgress`、`yearWearData`（懒加载）、`viewMode: 'month' | 'year'`。
- 异步拉取集中在 `reloadAll` 与切年视图时触发；`useFocusEffect` 刷新时一并更新 today/streak/progress。

## 空状态 / 边界

- 全新用户（无任何记录）：A 显示未记录 CTA；B 连续 0、进度 0/总；D 隐藏；月视图全灰格；年视图全底色。
- 翻到历史月：A、B 仍显示"今天/本月"；D 与概览显示该历史月数据（可能为空→隐藏）。

## 不在本次范围

- 天气/OOTD 照片日记、成就徽章系统、穿搭推荐 —— 数据层或交互较重，留待后续。
- `WearCalendarSheet` 内部不再改动。

## 风险

- 年度热力图整年查询 + 渲染 365 格：需注意首屏仅在切到「年」时加载，避免拖慢默认「月」视图。
- `MonthCalendar` 着色改动要保证对其他调用方（如有）无副作用 → 用可选 prop 默认不启用。
